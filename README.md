# BaiduAI

基于 **.NET Framework 4.8 + WinForms** 的百度 AI 人脸识别工作台：把本机 USB 摄像头与百度人脸识别接口结合起来，实现「图片人脸对比」与「刷脸注册 / 刷脸登录」。

界面按 **DSH 设计系统**（暗色基座、卡片、圆角、统一间距）用代码构建，并支持亮 / 暗主题切换。

## 功能

**图片模式**

- **选择人脸图片 + 开始对比**：依次选两张图片（自动填入 A / B），调用百度人脸比对接口并显示相似度

**摄像头模式**

- **连接 / 重新检测**：枚举 DirectShow 摄像头设备并打开实时预览
- **实时人脸框**：预览画面自动框出人脸（绿色），并同步更新年龄与人脸质量提示
- **拍照**：抓拍保存 JPG，显示年龄与美颜度
- **人脸注册 / 人脸登录**：把当前画面注册到指定用户组；登录时做人脸搜索，命中后播放欢迎语音

**通用**

- **亮 / 暗主题切换**：标题栏右上角按钮，配色取自 DSH 设计令牌
- **状态栏**：实时反馈操作结果与错误原因

## 运行要求

- Windows 10 / 11
- .NET Framework 4.8
- 一个可用摄像头
- 联网（人脸识别均为云端调用）
- 百度 AI 开放平台的**人脸识别**应用（需要 API Key / Secret Key）

## 配置（首次运行必做）

1. 登录 [百度智能云控制台](https://console.bce.baidu.com/)，在「人脸识别」应用中获取 **API Key** 与 **Secret Key**。
2. 打开 `BaiduAI\app.config`，填写 `ApiKey` 与 `SecretKey`：

   ```xml
   <appSettings>
     <add key="ApiKey" value="你的API Key" />
     <add key="SecretKey" value="你的Secret Key" />
   </appSettings>
   ```

3. 用 Visual Studio 打开 `BaiduAI.sln` 编译运行。

启动后标题栏的标记会显示「密钥已配置」，未填写时显示「未配置密钥」，调用接口会给出明确提示。

> **密钥安全**：本项目的密钥只从 `app.config` 读取，源码中不硬编码。
> 请不要把填了真实密钥的 `app.config` 提交到公开仓库；如果密钥曾经进入过版本库，请先到控制台**重置**。

## 使用流程

**照片对比**

```
点击「选择人脸图片」两次（分别填入图片 A / B）→ 点击「开始对比」→ 查看相似度
```

**建库并登录**

```
连接 → 填写「用户分组ID」+「用户姓名」→ 人脸注册
     → 对准摄像头，填写相同分组ID → 人脸登录
     → 命中：显示用户ID与相似度 + 播放欢迎语音
     → 未命中：状态栏提示
```

## 界面设计说明

配色、字体、圆角与控件尺寸均取自 DSH 前端的设计令牌（`--dsw-alias-*` / `--dsw-radius-*` / `--dsw-font-*`），
关键取值：

| 项目 | 取值 |
| --- | --- |
| 背景层级 | 亮 `#fff` / 暗 `#151517`（基座）、`#232324`（layer1）、`#2c2c2e`（layer2） |
| 主要文字 | 亮 `#0f1115` / 暗 `#f9fafb` |
| 描边 | 亮 `#00000029` / 暗 `#ffffff33` |
| 业务色（聚焦 / 强调） | 亮 `#4176e6` / 暗 `#7aaaff` |
| 成功色（人脸框） | `#22c55e` |
| 主按钮 | 亮 `#0f1115` / 暗 `#f9fafb`，高 36px，圆角 12px |
| 输入框 | 高 32px，圆角 12px，聚焦时描边变业务色 |
| 卡片 | 圆角 20px，1px 描边 |
| 字体 | `Microsoft YaHei UI` 14px；代码 `Consolas` 12px |
| 阴影 | 黑色低透明度柔和阴影（无彩色发光） |

> 说明：DSH 的圆角是超椭圆（`corner-shape: superellipse`），WinForms 无法实现，这里用普通圆角近似；
> DSH 用 `color-mix()` 生成的半透明叠加色，也折算成了等效实色。

## 界面自检（可选）

没有摄像头或密钥时，可用内置开关把界面渲染成图片，便于核对视觉稿：

```powershell
BaiduAI.exe --render-test D:\out\ui.png
```

会在 D 盘生成 `ui.png`；同目录的 `ui.png.log` 记录渲染步骤，便于排查。
正常双击运行不会命中该分支。
